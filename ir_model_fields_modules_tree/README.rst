============================
IR Model Fields Modules Tree
============================

This module helps migration analysis by exposing the ``modules`` field on
``ir.model.fields``:

* Adds ``modules`` to the list (tree) view of fields.
* Adds ``modules`` as a searchable filter field.
* Adds a ``Module`` option in Group By.
