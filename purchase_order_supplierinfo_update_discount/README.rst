===========================================
Purchase order supplierinfo update discount
===========================================

* When changing the discount on the purchase order line, change it in
  supplierinfo.
* When you change the discount or unit price on the purchase invoice line, also
  change it on the purchase order line.

Bug Tracker
===========

Bugs are tracked on `GitHub Issues
<https://github.com/avanzosc/odoo-addons/issues>`_. In case of trouble,
please check there if your issue has already been reported. If you spotted
it first, help us smash it by providing detailed and welcomed feedback.
