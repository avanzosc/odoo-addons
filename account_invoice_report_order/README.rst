============================
Account Invoice Report Order
============================

This module automatically sorts invoices in ascending order by invoice number in the Invoice Analysis pivot view.

Key Features
============

- Automatically sort invoices in **ascending order** by invoice number.
- Apply sorting specifically to the **Invoice Analysis** pivot view.
- Preserve the standard sorting behavior for other pivot views.
- Allow users to sort by numerical measures without overriding their selection.
- Improve invoice navigation and readability.

Configuration
=============

1. Go to **Accounting → Reporting → Invoice Analysis**.
2. Switch to the **Pivot** view.
3. Group rows by **Invoice Number**.
4. Invoices will automatically be displayed in **ascending order**.
5. Users can still sort by numerical measures using the standard pivot functionality.
