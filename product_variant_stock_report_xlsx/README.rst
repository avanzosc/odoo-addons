===========================
Product Variant Export XLSX
===========================

This module adds a wizard to export product variants to an XLSX report.

Features
--------

- Wizard available from *Inventory > Products > Export Product XLSX List*.
- Optional filters by company, family, subfamily, internal category and brand.
- Generates an XLSX report for ``product.product`` records including main product
  data (identifiers, names, type, flags, categories/brand, accounts, prices,
  units of measure, suppliers, routes, tracking, taxes, orderpoint data,
  weight and volume).
- Adds dynamic columns for all variant attributes found in the exported
  products.
