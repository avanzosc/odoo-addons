===============================
Stock Inventory Date Lot Filter
===============================

This module extends the stock inventory adjustment functionality by allowing users to filter the selected stock quants using two new fields:

- **Create Date Before**: Only include stock quants created before a specified date.
- **Lot Contains**: Only include stock quants with lot names containing a specific substring.
- Only include stock quants with a non-zero quantity, matching the previous
  inventory line loading behavior.

**Features**

- Adds two new fields to the inventory form:
  - `Create Date Before` (Datetime)
  - `Lot Contains` (Char)
- Filters the stock quants selected when the inventory adjustment starts according to these fields and excludes zero-quantity quants.
- Fully integrated with the inventory adjustment form view.
  
**Technical Details**

**New Fields**

- `create_date_before` (Datetime): Filters out any stock quant created on or after this date.
- `lot_contains` (Char): Filters out any lot whose name does not contain this substring (case-insensitive).

**Method Overrides**

Extends the stock quant domain generated by `stock.inventory` to apply the
custom filters before the inventory adjustment is started.
