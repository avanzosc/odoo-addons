========================================================
Stock Picking Report Valued Picking Stored True
========================================================

Overview
========

The **Stock Picking Report Valued Picking Stored True** module extends the **Stock Picking** functionality to include a "Valued Picking" field. This field can be used to store whether the picking is valued, providing greater flexibility in reporting and analysis of stock movements.

Features
========

- **Valued Picking Field**:

  - Adds a "Valued Picking" checkbox to the stock picking form to indicate whether the picking is valued or not.
- **Report Integration**:

  - This module can be integrated with reports that require a "valued" status for stock pickings.
- **User-friendly Interface**:

  - The "Valued Picking" field is easily accessible from the stock picking form view.

Testing
=======

1. Create or edit a stock picking.
2. Verify that the "Valued" field is visible and can be toggled.
