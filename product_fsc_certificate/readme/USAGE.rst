To use this module, you need to:

1. Configure the FSC certificate at the company level (see Configuration section).

2. Mark products as FSC-certified:

   * Go to Sales > Products > Products.
   * Open a product form.
   * In the "Options" tab, check the "Is FSC certificate" field.
   * Save the product.

3. The FSC status will automatically propagate to:

   * **Sale Orders**: When a sale order contains an FSC-certified product, the order is marked as FSC.
   * **Delivery Orders**: When a delivery contains FSC-certified products, the picking is marked as FSC.
   * **Invoices**: When an invoice contains FSC-certified products, the invoice is marked as FSC.

4. Reports will automatically display:

   * An asterisk (*) next to FSC-certified product names.
   * The FSC certificate logo and number at the bottom of the document.

5. To update FSC status for existing orders:

   * Go to Sales > Products > Products.
   * Select the FSC-certified products.
   * Click on Action > FSC Update Orders.
