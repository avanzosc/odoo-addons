==========================
Treasury forecast purchase
==========================

* This module extends the project treasury forecast to include confirmed
  purchase order lines as ``Committed Purchase`` movements.
* It allows purchase quotations to be created from treasury forecast cost
  lines, grouped by supplier.
* The generated purchase order lines are linked to their treasury forecast
  lines and assigned to the corresponding project.
