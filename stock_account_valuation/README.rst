=======================
Stock Account Valuation
=======================

This module stores the product category costing method and inventory valuation
method on stock valuation layers.

The fields are shown in the stock valuation layer list and form views, making it
easier to audit which costing and valuation configuration was used when each
stock valuation layer was created.
