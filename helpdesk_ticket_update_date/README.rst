===========================
Helpdesk Ticket Update Date
===========================

Add "Updated on" field to helpdesk ticket portal views showing last stage update date.

Description
-----------

This module extends the Helpdesk (Enterprise) QWeb portal views to display the `date_last_stage_update` field:

- In the ticket detailed view (`helpdesk.tickets_followup`).
- In the ticket list/tree view (`helpdesk.portal_helpdesk_ticket`).

This allows portal users to see when the ticket was last updated alongside the ticket creation date.

Usage
-----

- Install the module.
- Access the Helpdesk portal.
- The "Updated on" field will appear next to the "Reported on" field in the ticket detail and ticket list views.
