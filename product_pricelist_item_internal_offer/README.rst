=====================================
Product Pricelist Item Internal Offer
=====================================

**Add an internal offer field to pricelist items**

This module extends the Odoo *Product Pricelist Item* model to include an
internal text field that can be used to describe or identify internal offers,
promotions, or notes that should not be visible to customers.
