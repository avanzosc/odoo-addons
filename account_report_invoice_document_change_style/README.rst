============================================
Account Report Invoice Document Change Style
============================================

Overview
========

The **Account Report Invoice Document Change Style** module allows users to customize the style of the invoice report template in Odoo. This module enables the application of custom CSS styles to modify the appearance of the invoice document, such as font family, background color, and table styles.

Features
========

- **Customizable Invoice Style**:
  
  - Modify the CSS styles of the invoice report template.
  
  - Change font family, background color, and table styles.
  
  - Add any custom CSS for further customization.

Usage
=====

1. **Install the Module**:

   - Install the **Account Report Invoice Document Change Style** module from the Apps menu.

2. **View Style Changes in Invoice Report**:
   
   - After installation, the invoice report will reflect the custom styles defined in the module.

Configuration
=============

No additional configuration is required. The module automatically applies the customized styles to the invoice report.

Testing
=======

1. Generate an invoice report and verify that the changes in the style (e.g., font family, background color) are reflected in the document.
