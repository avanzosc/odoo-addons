==============================
Stock Move Line Display Fields
==============================

This module extends the stock.move.line model in Odoo by adding new fields and improving existing views. 
It enhances stock tracking and cost visibility by incorporating purchase cost details and packaging-related information. 
The modifications ensure better organization and transparency in stock movement operations.
