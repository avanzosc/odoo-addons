================================
Product Pricelist Item Discounts
================================

This module adds a wizard to apply a percentage change to selected pricelist
items.

The wizard allows selecting which pricelist item price fields must be updated:

* Price.
* PVP.
* Distribution Price.

The change can be applied as a discount or as an increment.

Usage
=====

#. Go to pricelist items.
#. Select one or more items.
#. Open the "Apply Discounts" action.
#. Enter the percentage to apply.
#. Select the price fields to update.
#. Enable "Positive" to apply the percentage as an increment.
#. Apply the wizard.
