===========================
Stock Picking Date Deadline
===========================

* This module allows displaying the 'Deadline' field (`date_deadline`) 
  in the form view of detailed operations in stock pickings.

* The field already exists in the "Operations" tab and now it is also visible 
  when opening a line from the "Detailed Operations" tab.
