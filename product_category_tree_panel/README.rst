===========================
Product Category Tree Panel
===========================

This module adds a hierarchical search panel to the product category list.
The panel shows parent categories as an expandable tree and allows users to
filter the list by selecting a category branch.

Usage
=====

To use this module:

#. Go to **Inventory > Configuration > Products > Product Categories**.
#. Expand the category tree in the left search panel.
#. Select a parent category to filter the product category list.
