=======================
Partner Default Address
=======================

This module lets you define one default invoice address and one default delivery address per partner.
These defaults are applied automatically when creating quotations, sales orders, and invoices.

Features
========

* Add two checkboxes on contacts: **Default Invoice Address** and **Default Delivery Address**.
* Enforce a single default per partner for each address type.
* Auto-fill invoice and delivery addresses when creating documents.
* Still allow manual changes on each document when needed.

Usage
=====

1. Open a customer.
2. In the contact list, mark one contact as **Default Invoice Address** and another as
   **Default Delivery Address**.
3. Create a quotation or invoice: the addresses are prefilled automatically.
