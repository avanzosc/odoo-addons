==============================
Product Technical Sheet Report
==============================

* Adds a technical sheet PDF report to product variants.
* Shows product, shape, transfer, ply composition and finish information.
* Uses the product and transfer images for the sample and graphic sections.

Bug Tracker
===========

Bugs are tracked on `GitHub Issues
<https://github.com/avanzosc/odoo-addons/issues>`_. In case of trouble,
please check there if your issue has already been reported. If you spotted
it first, help us smash it by providing detailed and welcomed feedback.

Do not contact contributors directly about support or help with technical issues.
