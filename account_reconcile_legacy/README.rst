========================
Account Reconcile Legacy
========================

This module adds a legacy-style manual reconciliation client action, inspired
by the Odoo 12 reconciliation view, while using Odoo 18 accounting structures
and the Enterprise accounting reconciliation wizard.

It adds a separate accounting menu entry for the classic manual reconciliation
screen, allowing users to choose between the current Odoo 18 reconciliation
flow and the legacy-style workflow.
