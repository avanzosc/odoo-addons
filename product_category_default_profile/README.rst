================================
Product Category Default Profile
================================

* This module allows products to be marked as profiles and assigned as default
  profiles on product categories and category attribute profiles.
* When a product is created, it copies the configured routes, product type,
  purchase and sales settings, accounts, units of measure, and transfer
  requirement from its profile product.
