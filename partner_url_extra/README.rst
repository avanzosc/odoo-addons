=================
Partner URL Extra
=================

This module adds an extra URL field to the partner form, also available for companies.

* In the partner form, an "extra URL" field is added in the Sales tab
* The field allows storing links to SharePoint with technical information, plans, and documentation
* The link is clickable in both form view and list view
