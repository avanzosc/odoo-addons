=========================
Stock Location Tree Panel
=========================

This module adds a hierarchical search panel to the stock location list.
The panel shows parent locations as an expandable tree and allows users to
filter the list by selecting a location branch.

Usage
=====

To use this module:

#. Go to **Inventory > Configuration > Warehouse Management > Locations**.
#. Expand the location tree in the left search panel.
#. Select a parent location to filter the stock location list.

The **Locations** menu is available when the *Storage Locations* setting is
enabled.
